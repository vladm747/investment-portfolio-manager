# Знімки екранів Portfolio Manager

Знімки зроблено на фінальній версії клієнта в обох темах. Роздільна здатність ×2 (наприклад, 2560 px завширшки
для екрана 1280 px).

```
light/ та dark/              світла та темна теми
  desktop/                   1280 px
  tablet-768/                768 px
  mobile-360/                360 px
```

## Екрани (desktop)

| Файл | Що показано |
| --- | --- |
| `01-sign-in` | Вхід |
| `02-sign-up` | Реєстрація (той самий макет, що й вхід) |
| `03-sign-in-error` | Вхід: повідомлення про помилку |
| `04-portfolios` | Список портфелів: показники, таблиця |
| `05-portfolios-row-menu` | Меню дій у рядку портфеля (⋮) |
| `06-create-portfolio-validation` | Діалог створення портфеля: перевірка назви |
| `07-delete-portfolio-confirm` | Підтвердження видалення портфеля |
| `08-user-menu` | Меню користувача з виходом |
| `09-dashboard` | Огляд портфеля: показники, графік, сектори, позиції |
| `10-dashboard-growth-3m` | Графік за період «3М» |
| `11-dashboard-chart-tooltip` | Підказка на графіку |
| `12-positions-row-menu` | Меню позиції: «Змінити кількість», «Видалити» |
| `13-change-quantity-dialog` | Діалог зміни кількості |
| `14-delete-position-confirm` | Підтвердження видалення позиції |
| `15-add-position-validation` | Діалог додавання позиції: перевірка полів |
| `16-optimisation-loading` | Оптимізація: повідомлення про розрахунок |
| `17-optimisation` | Оптимізація: порівняння ваг і показників |
| `18-dashboard-empty` | Порожній портфель |
| `19-portfolio-load-error` | Портфель не відкрився: помилка з повтором |
| `20-not-found` | Сторінку не знайдено |

На `tablet-768` і `mobile-360` зроблено основні екрани: вхід, реєстрація, список портфелів, огляд, оптимізація
(завантаження й результат), порожній портфель, помилка, 404.

## Про дані

Усі суми на знімках — **вигадані приклади** з локальної бази. Ціни акцій не отримувалися з Yahoo Finance, а графік
динаміки й результат оптимізації взято з тимчасової заміни математичного сервісу (ті самі формати відповідей,
вигадані числа). Для тексту диплома це не має значення, але не видавайте ці цифри за реальні результати.
